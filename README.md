# MIF Smart

A chat-first business application with customer bottom navigation, account-gated ERP operations, a real appointment calendar, private conversation history, and central platform-owned OpenAI settings. No old store or marketing site.

See [Arabic operations and setup guide](MIF_SMART_SETUP_AR.md) for service configuration, account bootstrap, platform-owner credentials, mobile installation, production safeguards, and operational boundaries.

`npm install && npm run check` validates the source, but real customer access requires permanent deployment with actual database/session secrets.
